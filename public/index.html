Модели режима «Компьютер»

Агент сам подбирает модель под каждую задачу/подзадачу по её возможностям (авто-разметка по имени модели). Можно поправить вручную — отмеченные возможности заменяют авто-разметку для этой модели.

Выполнение кода

Кнопка «Запустить» на блоках кода в чате выполняет код в изолированном контейнере (Piston) и не имеет доступа к вашим файлам, сети сервера и остальной инфраструктуре. Каждый запуск ограничен по времени, памяти и объёму вывода.

Разрешить модели запускать код самостоятельно
Включает автономный вызов инструмента run_code через function calling: модель сама решает, нужно ли выполнить код для ответа (до 3 раундов на сообщение), без нажатия кнопки «запустить». Действует в тех же изолированных условиях и лимитах, что и ручная кнопка.

Память

Короткая заметка о вас, которую агент будет учитывать в любом диалоге — простая свободная заметка, а не автоматическое запоминание. Например: «работаю с PowerShell и Keenetic, предпочитаю краткие ответы».

Планировщик

Периодический запрос к выбранной модели через заданный интервал (в минутах, без cron-синтаксиса). Результат появляется как новое сообщение в отдельном треде чата.
